项目简介

一套完全本地运行的双色球历史数据统计与回测验证工具，包含 Windows 桌面版（Python + PySide6）与 Android 版（Java + Chaquopy 内嵌 Python 引擎），统计引擎与数据层在两端共用同一套实现。支持历史开奖数据导入（联网同步 / CSV / 粘贴）、25+18 统计模块、双轨选号机制、滚动回测与随机基准对照，全部数据与运算在本机完成，不依赖外部服务。

主要功能

  • 历史开奖数据：福彩官网接口联网同步、CSV 导入、粘贴导入，SQLite 本地存储
  • 统计引擎：43 个统计模块（频率、冷热、遗漏、奇偶、和值、跨度、形态约束等）
  • 双轨选号机制：号码轨迹 + 区块轨迹独立评分，六组结果相互交叉验证
  • 滚动回测：walk-forward 回测 + 随机基准对照，诚实展示统计选号对开奖无预测能力
  • 桌面版可打包独立 EXE；安卓版内置 Python 引擎，全部本地运行
