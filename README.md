# 双色球历史统计工具（桌面版 + 安卓版）

一套完全本地运行的双色球历史数据统计、选号参考与回测验证工具。包含 Windows 桌面版（Python + PySide6）与 Android 版（Java + Chaquopy 内嵌 Python 引擎），统计引擎与数据层在两端共用同一套实现。

> **客观结论（请先读）**：双色球每期开奖为独立随机事件，任何统计方法都无法预测下一期号码。本项目是历史数据统计与概率学习的参考工具，**不能预测开奖、不构成任何投注建议、不涉及售彩与代购**。请理性购彩，量力而行；未成年人禁止购彩。

## 功能总览

- **历史数据**：内置福彩双色球全量历史开奖（2003001 期起，约 3510 期，公开数据），支持手动联网同步、CSV 文件导入、粘贴导入
- **统计引擎（43 个统计模块）**：冷热频次、遗漏值、区间分布、形态约束、蓝球双轨等，每个模块独立打分后投票汇总
- **双轨选号机制**：
  - 号码轨道：按单个号码评分选号
  - 区块轨道：按号码组合区块整体评分选号
  - 横向叠加：对两轨结果做交集与补集运算
  - 六组结果（结果 1~6），其中结果 2 包含结果 1、4 包含 3、6 包含 5 的包含关系由同一套评分条件自然涌现，用于相互验证程序正确性，并非强行指定
- **回测与随机基准**：walk-forward 滚动回测，统计六组结果相对随机选号（红球约 1.09 个/期、单注蓝球 6.25%）的真实表现，并给出奖级分布
- **一机一码授权（仅安卓正式版）**：设备绑定 + RSA-2048 离线激活码，防止转发滥用（见下文授权说明）

## 目录结构

```
.
├── app/                    # 桌面版（Python + PySide6）
│   ├── main.py             #   入口
│   ├── ui_main.py          #   PySide6 界面
│   ├── engine.py           #   统计引擎（43 模块 + 双轨选号）
│   ├── db.py               #   SQLite 数据层
│   ├── backtest.py         #   滚动回测与奖级判定
│   └── data_fetch.py       #   福彩官网公开接口拉取
├── android_app/            # 安卓版（Java + Chaquopy 内嵌 Python 引擎）
│   └── app/src/main/       #   Java 界面 + Python 引擎 + 内置数据库
├── data/ssq.db             # 福彩公开历史开奖数据（SQLite）
├── scripts/                # 开发调试脚本（接口探测、冒烟测试等）
├── tests/                  # 验证脚本（引擎、回测、排除、包含关系等）
├── requirements.txt        # 桌面版 Python 依赖
└── LICENSE                 # GNU GPL v3
```

## 桌面版构建与运行

```bash
# 依赖
pip install -r requirements.txt        # PySide6、pyinstaller（打包用）

# 运行
python app/main.py

# 打包为独立 EXE（PyInstaller）
pyinstaller 双色球智能选号.spec        # 参考根目录 build/ 下的打包配置
```

桌面版完全本地运行，首次启动使用内置 `data/ssq.db`，支持在界面中联网同步或导入补充数据。

## 安卓版构建

工程位于 `android_app/`，使用 Gradle + Chaquopy（Python 3.11 内嵌）：

- `app/src/main/python/`：与桌面版共用的统计引擎、数据层、回测与激活验证（Python）
- `app/src/main/java/`：安卓界面与桥接（Java）
- 内置数据库位于 `app/src/main/assets/ssq.db`

```bash
cd android_app
# debug 构建（无需签名配置）
gradle :app:assembleDebug
```

开源版不包含作者的 release 签名配置（正式发布版由作者使用独立密钥签名，用于一机一码授权分发）；源码使用者可自行配置签名或直接使用 debug 构建。

## 数据来源与说明

- 历史开奖数据来自中国福利彩票发行管理中心官网公开开奖公告（https://www.cwl.gov.cn ），属公开的客观事实数据
- 安卓版「同步开奖数据」按钮仅在用户手动点击时联网拉取公开开奖记录，**不上传任何本机数据**
- 内置库为项目开源时的快照，可通过界面同步/导入功能更新

## 授权机制说明（仅安卓正式版）

- 正式版采用「一机一码」：每台设备首次运行显示专属设备码，需向作者换取离线激活码，激活码由作者持有的私有密钥签名，**仅对生成它的设备有效，转发无效**
- 本仓库包含激活码的**验证**实现（RSA 公钥验签，位于 `android_app/app/src/main/python/auth.py`），**不包含**作者私有密钥
- 开源使用者可自行更换密钥对或移除激活逻辑
